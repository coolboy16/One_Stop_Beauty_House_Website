ONE STOP BEAUTY HOUSE WEBSITE

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install/use the Live Server extension in VS Code.
4. Right-click index.html → Open with Live Server.

Pages:
- index.html — home, services and contact
- booking.html — booking form
- css/style.css — pink/black design
- js/booking.js — sends booking request to WhatsApp
- js/main.js — mobile menu
